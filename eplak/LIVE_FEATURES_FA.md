# دو بخش جدید: اخبار و دانستنی‌ها + ارسال اعلان

**تاریخ:** ۷ سپتامبر ۲۰۲۶

---

## ۱. اخبار و دانستنی‌ها (مدیریت زنده)

یک بخش کامل در پنل ادمین برای مدیریت محتوای خبری؛ هر تغییر **بلافاصله** در اپلیکیشن نمایش داده می‌شود.

### صفحات ادمین

| صفحه | کاربرد |
|---|---|
| `admin/news.php` | فهرست مطالب با فیلتر (همه / اخبار / دانستنی‌ها)، تغییر وضعیت انتشار، ویرایش، حذف |
| `admin/news_add.php` | افزودن مطلب جدید |
| `admin/news_edit.php` | ویرایش مطلب |

### امکانات هر مطلب

- **بخش:** اخبار و اطلاعات 📰 / دانستنی‌های ورامین 🏛️
- عنوان، خلاصه (نمایش در فهرست)، متن کامل
- آیکون (ایموجی)، تصویر (نشانی اینترنتی - اختیاری)
- ترتیب نمایش، وضعیت انتشار (منتشر شده / پیش‌نویس)

### محل نمایش در اپ (طبق انتخاب شما)

- تب **«اخبار و اطلاعات»** ← مطالب نوع «خبر»
- تب **«دانستنی‌های ورامین»** ← مطالب نوع «دانستنی» (در کنار کارت‌های تصویری موجود)
- نوار **«آخرین اخبار» در پیشخوان** ← ۲ خبر آخر

### مکانیزم به‌روزرسانی

ماژول `modules/live.js` هر ۶۰ ثانیه (و هنگام ورود) محتوا را از پایگاه داده می‌خواند.
اگر ارتباط قطع باشد، محتوای پیش‌فرض برنامه بی‌تغییر می‌ماند و **هیچ خطایی نمایش داده نمی‌شود**.

---

## ۲. ارسال اعلان (تکی و گروهی)

### صفحات ادمین

| صفحه | کاربرد |
|---|---|
| `admin/notifications.php` | ارسال اعلان جدید + تاریخچه ارسال‌ها |
| `admin/notification_view.php` | مشاهده گیرندگان و وضعیت خوانده شدن |

### روش‌های ارسال (طبق انتخاب شما)

1. **ارسال به همه کاربران** — یک کلیک برای کل کاربران
2. **ارسال تکی** — انتخاب یک کاربر از فهرست
3. **ارسال دسته‌ای** — تیک زدن چند کاربر دلخواه (با جستجو بر اساس نام یا شماره، و دکمه انتخاب همه)

### وضعیت تحویل

در صفحه جزئیات هر ارسال: تعداد گیرندگان، خوانده شده / خوانده نشده، و زمان دریافت.

---

## ۳. تغییرات فنی

### پایگاه داده

| جدول | توضیح |
|---|---|
| `news` | مطالب اخبار و دانستنی‌ها |
| `notification_sends` | هر بار ارسال (برای تاریخچه) |
| `notifications.send_id` | اتصال اعلان‌های کاربران به ارسال اصلی |

### API

| مسیر | کاربرد |
|---|---|
| `api/news.php` | دریافت مطالب منتشرشده (وب) — پشتیبانی از `type` و `limit` |
| `api/notifications.php` | دریافت اعلان‌های یک کاربر + علامت‌گذاری خوانده‌شده |
| `GET /news` (بکند Node) | همان برای اندروید |
| `GET /notifications/:phone` (بکند Node) | همان برای اندروید |

### یکسان‌سازی پایگاه داده

دو پایگاه داده وجود داشت: `wigitali_eplak-db` (پنل ادمین و وب) و `eplak_db` (بکند اندروید) که محتوای یکسانی داشتند.
جدول‌های جدید در هر دو ساخته شد و بکند اندروید اکنون به همان پایگاه پنل ادمین متصل است تا **یک منبع واحد** باشد
(در صورت نیاز با متغیر محیطی `EPLAK_DB_NAME` قابل تغییر است).

### فایل‌های جدید / تغییرکرده

| فایل | توضیح |
|---|---|
| `admin/news.php`, `news_add.php`, `news_edit.php` | مدیریت مطالب |
| `admin/notifications.php`, `notification_view.php` | ارسال و گزارش اعلان |
| `admin/includes/functions.php` | توابع اخبار و اعلان |
| `admin/actions.php` | حذف و تغییر وضعیت مطلب |
| `api/news.php`, `api/notifications.php` | API وب |
| `modules/live.js` | همگام‌سازی زنده در اپ |
| `backend/server.js` | مسیرهای اندروید |
| سایدبار ۱۷ صفحه ادمین | پیوندهای بخش‌های جدید |

## ۵. نکته برای اندروید

اپ اندروید محتوا را از طریق WebView با نشانی `https://eplak.ir/eplak-fixed/api` می‌خواند.
برای اتصال به سرور خودتان، در `assets/index.html` (یا پیش از بارگذاری اسکریپت‌ها) این متغیر را تنظیم کنید:

```js
window.EPLAK_API_BASE_URL = 'https://سرور-شما/eplak-fixed/api';
```
