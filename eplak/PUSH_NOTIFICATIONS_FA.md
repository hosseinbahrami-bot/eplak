# اعلان روی صفحه گوشی در ای‌پلاک

اعلان‌های پنل ادمین از این مسیر کار می‌کنند:

1. اپ، Service Worker را ثبت می‌کند و بعد از اجازه کاربر، subscription پوش را در جدول `push_subscriptions` ذخیره می‌کند.
2. پنل، متن اعلان را در `notifications` ذخیره می‌کند و برای گوشی‌های ثبت‌شده همان کاربران Web Push می‌فرستد.
3. در PWA، چه برنامه باز باشد و چه در پس‌زمینه یا بسته، Service Worker اعلان سیستم‌عامل را با صدای پیش‌فرض گوشی و الگوی ویبره `[250, 100, 250]` نشان می‌دهد.
4. در APK اندروید، `NotificationWorker` در پس‌زمینه API را بررسی می‌کند و در حالت باز نیز bridge جاوااسکریپت مستقیماً `NotificationManager` را صدا می‌زند؛ هیچ بنر یا صدای اختصاصی داخل برنامه جای اعلان سیستمی را نمی‌گیرد.
5. با لمس اعلان، صفحه اعلان‌های ای‌پلاک باز می‌شود و فهرست داخل برنامه نیز همگام می‌گردد.

## تنظیم یک‌باره سرور

برای ارسال واقعی Web Push باید کلیدهای VAPID روی سرور PHP تنظیم شوند. کلید خصوصی را در GitHub قرار ندهید.

```bash
npx web-push generate-vapid-keys
```

سپس یکی از دو روش زیر را انجام دهید:

### متغیرهای محیطی

```text
VAPID_PUBLIC_KEY=...
VAPID_PRIVATE_KEY=...
VAPID_SUBJECT=mailto:admin@your-domain.example
```

### فایل خصوصی PHP

فایل `shared/config.example.php` را به `shared/config.php` کپی کنید و این سه مقدار را وارد کنید:

```php
'vapid_public_key'  => '...',
'vapid_private_key' => '...',
'vapid_subject'     => 'mailto:admin@your-domain.example',
```

در اولین درخواست پنل یا API، migration جدول‌های `news`، `notification_sends`، `push_subscriptions` و ستون `notifications.send_id` به‌صورت خودکار اجرا می‌شود. اگر VAPID تنظیم نشده باشد، ارسال اعلان داخل پنل و همگام‌سازی داخل اپ همچنان کار می‌کند و فقط پوش خارج از برنامه فعال نمی‌شود.

> صدای اعلان خارج از برنامه توسط سیستم‌عامل و تنظیمات صدای اعلان گوشی کنترل می‌شود؛ سایت نمی‌تواند صدای گوشی را در حالت بی‌صدا به‌زور فعال کند.
